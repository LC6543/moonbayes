# Changelog

## 0.1.0

- add validated finite discrete variables
- add dense factor tables with row-major assignments
- add factor multiplication, marginalization and normalization
- add evidence restriction with duplicate, unknown and range checks
- add validated Bayesian-network nodes, CPT checks and topological ordering
- add exact variable-elimination queries with minimum-fill ordering
- add ancestor, descendant and d-separation structure queries
- add scaled evidence likelihood with underflow-safe log probabilities
- add deterministic likelihood-weighting sampling with effective sample size
- add deterministic ancestral sampling of complete joint assignments
- add MAP/MPE assignments through exact posterior maximization
- add versioned JSON model import and export
- add a command-line tool for validation, queries, likelihood, MAP and export
- add complete-data CPT fitting with configurable smoothing
- add deterministic inference plans with bucket-size diagnostics
- add immutable CPT replacement and variable renaming
- add end-to-end acceptance example, compatibility notes and release checklist
- add structured errors and table-size bounds
- add focused factor tests and a runnable example
